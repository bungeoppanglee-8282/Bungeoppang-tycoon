# 뮤직티처 (Music Teacher)

브라우저에서 실행하는 악기 연습 웹앱. 빌드·설치 없이 정적 파일만으로 동작합니다.

## 실행

```bash
cd music-teacher
python3 -m http.server 8000     # 또는 npx serve
# 브라우저에서 http://localhost:8000
node tests/run.mjs              # 로직 자체 검사 (10개)
```

마이크·탭 오디오·음성 인식은 `localhost` 또는 HTTPS에서만 동작합니다.

## 구성

| 파일 | 역할 |
| --- | --- |
| index.html / style.css | 벤토 그리드 UI (중요도 순 크기: 플레이어 > 악보 > 건반 > 티처 > 설정·악기 > 메트로놈·믹스·음성) |
| js/app.js | 플레이어, 건반, 오선지, 구간 반복, 기타·플루트, 녹음·비교, 메트로놈, 믹스, 스피커, 음성, 자동 저장 |
| js/midi.js | MIDI 파서 (형식 0·1, PPQ, 템포 변경) |
| js/pitch.js | 스펙트럼 배음 합산으로 다성 음 추정, 업로드 녹음 분석용 FFT |
| js/compare.js | 기준 MIDI와 감지 음 비교 (±0.7초, 0.26초 초과 시 빠름/늦음) |
| js/commands.js | 4개 언어 호출어 + 음성 명령 해석 |
| js/i18n.js | 한국어·영어·중국어·일본어 전체 문구 |
| js/instruments.js | 기타 12코드, 플루트 C4–C6 반음 운지 |
| js/wav.js | 합친 결과 WAV 인코딩 |
| sounds/*.mp3 | earshot으로 생성한 효과음 (메트로놈 강박·약박, 녹음 시작, 성공, 오류, 음성 명령 확인) |

## 이전 문서(Piano Lens) 대비 보완

- 업로드한 녹음 파일도 기준 MIDI와 비교 분석
- 녹음 합친 결과 WAV 파일로 저장
- 오류·상태 메시지까지 4개 언어 전부 번역 (테스트로 키 누락 검사)
- 메트로놈 켜기/끄기·템포, 믹스 재생/저장, 이어하기를 음성 명령에 연결
- 플루트 운지 C4–C6 반음 전체, 기타 코드 6 → 12개
- MIDI 트랙 길이 계산 버그 수정을 포함한 자체 테스트

## 여전히 남은 한계

- 유튜브 URL만으로 음·악보를 자동 추출하지 않음 → “탭 소리 연결”로 소리를 공유하거나 같은 곡 MIDI 연결
- 유튜브 속도는 플레이어가 허용하는 가장 가까운 값
- 음 인식은 배음 기반 추정 (반주·화음이 많으면 오인식)
- 비교는 음 높이·시점 비교이며 생성형 AI 수업이 아님
- 블루투스 페어링은 기기 설정에서, 출력 선택은 `selectAudioOutput` 지원 브라우저(Chrome 계열)만
- 업로드 녹음은 녹음 시작 = MIDI 0초로 가정
